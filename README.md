# Семинар материалдары — платный доступ через Kaspi + подтверждение в Telegram

Сайт с материалами семинара. Все видят список материалов, но открыть и скачать их можно только после оплаты:
человек переводит деньги на ваш номер Kaspi и нажимает «Төледім», вам в Telegram приходит заявка, вы проверяете
перевод в приложении Kaspi и нажимаете «✅ Растау». После этого у человека открываются **все** материалы.

Платёжные шлюзы не используются, ИП не нужен.

## Как это устроено

```
public/index.html   — сайт (дизайн, модальные окна оплаты)
public/kaspi-qr.png — (необязательно) картинка QR Kaspi, показывается в окне оплаты
private/            — PDF-файлы. Эта папка НЕ раздаётся напрямую
materials.json      — список материалов (белый список файлов)
server.js, src/     — сервер Node.js + Express, база SQLite, Telegram-бот
scripts/e2e-test.js — автоматическая проверка всего сценария (npm test)
```

Файлы отдаются только через `/api/download/<id>` и `/api/view/<id>`, и только если в браузере есть cookie
с действующим токеном доступа. По прямой ссылке без оплаты скачать файл нельзя.

После подтверждения человек получает:
- cookie на 1 год (доступ запоминается в браузере);
- личную ссылку вида `https://ваш-сайт/access/<токен>`: по ней можно открыть доступ на другом телефоне или после очистки браузера.

Если человек потерял доступ, он нажимает «Бұрын төледім» и вводит свой номер. Вам в Telegram придёт запрос с кнопкой
«🔓 Қолжетімділікті қайтару». В сообщении бот сам подскажет, есть ли оплата с этого номера.

## Шаг 1. Создать Telegram-бота

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Придумайте имя и username бота (username должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** вида `1234567890:AAE...`. Это значение `BOT_TOKEN`. Никому его не показывайте.
   Если токен утёк, получите новый у BotFather: `/revoke`.

## Шаг 2. Узнать свой ADMIN_CHAT_ID

1. Задеплойте сайт (шаг 3), указав пока только `BOT_TOKEN`. Можно и локально, см. «Запуск на компьютере».
2. Откройте своего бота в Telegram и нажмите **Start** (или отправьте `/start`).
3. Бот ответит: `Сіздің chat id: 123456789`. Это число и есть `ADMIN_CHAT_ID`.
4. Впишите его в переменные Railway. Сервис перезапустится, и бот начнёт присылать заявки вам.

Нажимать кнопки и пользоваться командами может только этот chat id, остальным бот отвечает «Рұқсат жоқ».

Команды бота:
| Команда | Что делает |
|---|---|
| `/start` | показывает ваш chat id |
| `/pending` | неподтверждённые заявки (с кнопками) |
| `/orders` | последние 10 заявок |
| `/stats` | сколько оплат и на какую сумму: сегодня и всего |

## Шаг 3. Деплой на Railway

Деплой делается через Railway CLI из папки проекта, потому что материалы из `private/` не лежат в GitHub:
```bash
railway login
railway init            # создать проект (один раз)
railway up              # загрузить и задеплоить текущую папку (каждый раз после изменений)
```
Railway сам увидит `package.json` и запустит `npm start` на Node 20.

### Подключить Volume (обязательно!)
Без Volume база заявок будет стираться при каждом деплое, и все оплатившие потеряют доступ.

1. В проекте Railway: правый клик по сервису → **Attach Volume** (или *New → Volume*).
2. **Mount path**: `/data`.
3. В переменных сервиса укажите `DATA_DIR=/data`.

### Прописать переменные (Service → Variables)
| Переменная | Пример | Описание |
|---|---|---|
| `BOT_TOKEN` | `1234567890:AAE...` | токен от BotFather |
| `ADMIN_CHAT_ID` | `123456789` | ваш chat id (шаг 2) |
| `KASPI_PHONE` | `+77001234567` | номер Kaspi для переводов |
| `PRICE` | `666` | цена полного доступа в тенге |
| `SITE_URL` | `https://xxx.up.railway.app` | адрес сайта, без `/` в конце |
| `DATA_DIR` | `/data` | путь к Volume |
| `PORT` | — | Railway задаёт сам, не трогайте |
| `SUPPORT_CONTACT` | `+7 700 123 45 67` или `@username` | *(необязательно)* контакт, который видит человек, если платёж не найден |
| `ORDER_RATE_LIMIT` | `5` | *(необязательно)* сколько заявок можно создать с одного IP за 10 минут |

Адрес сайта: **Settings → Networking → Generate Domain**. Его же впишите в `SITE_URL`.
QR-код для буклета делайте на этот адрес (или на свой домен, если подключите его там же).

## Материалы: как заменить своими

Сейчас продаётся **один товар**: архив `private/seminar-materials.zip` со всеми материалами внутри
(тестовый — собран из папки «Материалы Ару Базарбаевна»). Одна оплата открывает всё, что перечислено в `materials.json`.

> ⚠️ **Материалы не хранятся в GitHub.** Репозиторий публичный, поэтому всё в `private/` занесено в `.gitignore`
> (кроме демо-PDF для теста). На Railway файлы попадают командой `railway up` из этой папки
> (это разрешено в `.railwayignore`). После изменения материалов **всегда** выполняйте `railway up`.

### Заменить архив
1. Сложите все материалы в одну папку и запакуйте в ZIP (на Mac: правый клик → «Сжать»).
2. Положите архив в `private/` под именем `seminar-materials.zip` (с заменой).
3. `railway up`. Размер на сайте пересчитается сам.

### Или показывать файлы отдельными карточками
Положите файлы в `private/` и перечислите их в `materials.json`:
```json
[
  {
    "id": "trening",
    "title": "Тренинг материалы",
    "description": "«Өз-өзіңді жақсы көр» психологиялық тренингінің жоспары",
    "filename": "trening-2026.pdf",
    "tag": "Тренинг",
    "downloadName": "Тренинг материалы.pdf"
  }
]
```
- `id`: короткий код латиницей (используется в ссылке `/api/download/trening`), у каждого файла свой;
- `filename`: имя файла в `private/` (лучше латиницей, без пробелов);
- `downloadName`: *(необязательно)* с каким именем файл скачается у человека, можно по-казахски;
- `size`: *(необязательно)* подпись размера, например `"1,2 МБ"`. Если не указать, посчитается автоматически.

У PDF и картинок есть кнопка «Ашу» (открыть в браузере). У ZIP, DOCX и PPTX только «Жүктеу».
Пример с пятью отдельными PDF лежит в `scripts/materials.demo.json`.

Также уберите фразу «Демо нұсқа: файлдар үлгі ретінде қойылған…» в `public/index.html` (блок `<p class="note">`).

## Как поменять цену

Поменяйте переменную `PRICE` в Railway (например, `990`). Сайт и бот возьмут новую цену после перезапуска.
У старых заявок сохраняется сумма, по которой они создавались.

## QR Kaspi (необязательно)

Положите картинку в `public/kaspi-qr.png`, и она появится в окне оплаты. Если файла нет, блок скрыт.

## Запуск на компьютере

Нужен Node.js 20.

```bash
npm install
cp .env.example .env    # и заполните значения
npm start               # http://localhost:3000
```

Проверка всего сценария (заявка → подтверждение через имитацию кнопки в Telegram → скачивание,
закрытость файлов без токена, path traversal, rate limit):

```bash
npm test
```

Тест не подключается к настоящему Telegram и не трогает вашу базу.

## Важно знать

- **Один бот — один запущенный сервер.** Бот работает через long polling, поэтому если одновременно запустить
  его локально и на Railway с одним `BOT_TOKEN`, они будут мешать друг другу. Для локальных экспериментов
  остановите один из них или заведите отдельного тестового бота.
- **Лимит 5 заявок за 10 минут с одного IP.** Если на семинаре все сидят через один Wi-Fi колледжа, у них один
  внешний IP. При потоке заявок увеличьте `ORDER_RATE_LIMIT` (например, до `50`) на время семинара.
- Если по номеру уже есть неподтверждённая заявка, повторное «Төледім» не создаёт новую, а возвращает её.
- Резервная копия базы: файл `seminar.db` в Volume (`/data`).
